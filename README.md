# Product App

## Setup

### 1. Open Main Folder

```bash
cd inter_host_remote_app
```

### 2. Create Product App Folder

```bash
mkdir product_app
cd product_app
```

### 3. Clone Repository

```bash
git clone <PRODUCT_REPOSITORY_URL> .
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Start Application

```bash
npm start
```

Product App runs on:

```text
http://localhost:3001
```
